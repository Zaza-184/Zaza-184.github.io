# كتالوج ZAZA بتاع ألعاب

الكتالوج مستقل تمامًا: كل بياناته ملفات جوه الفولدر ده، ومفيش أي داتابيز.

## النشر على GitHub (مرة واحدة)
1. اعمل Repository جديد وارفع كل محتويات الفولدر ده.
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / root.
3. اللينك هيبقى: `https://USERNAME.github.io/REPO/`

## الأقسام (التبويبات)
| القسم | مصدره | السعر |
|---|---|---|
| PS4 معدّل | صور في `icons/` | 50 ج |
| PS5 معدّل | صور في `icons-ps5/` | 50 ج |
| PS3 معدّل | صور في `icons-ps3/` | 30 ج |
| غير معدّل | `Originals.xlsx` | Off / Online / Pr لكل لعبة |
| أكونتات PS4 / أكونتات PS5 | `Products.xlsx` (C = المنصة: PS4 أو PS5 أو PS4 + PS5) | B اختياري |
| ملحقات | `Accessories.xlsx` | B |

الأكونت اللي منصته PS4 + PS5 بيظهر في التبويبين. لو عمود C فاضي، المنصة بتتحدد من الاسم (لو فيه PS5)، وغير كده PS4.

أيقونات الألعاب اللي مش في قوايم المعدّل (الأكونتات وغير معدّل) حطها في `icons-extra/` بنفس اسم اللعبة، ومش هتظهر كلعبة معدّلة.

التبويب بيظهر أول ما يبقى فيه لعبة. اسم الصورة = اسم اللعبة (webp). أسعار الأقسام ومسميّاتها في `config.json` ← `sections`، و`modded_prices` لسعر لعبة بعينها. قسم جديد؟ ضيف فولدر أيقونات وسطر في `sections`.

## التصنيف
`Genres.xlsx` (A اسم اللعبة، B التصنيف). اللعبة ممكن تبقى في أكتر من تصنيف بعلامة `+`. تصنيف جديد؟ اكتبه وهيظهر كزر لوحده. بينطبق على كل قوائم الألعاب.

## التحديث
بعد أي تعديل شغّل: `python update.py` (محتاج `pip install openpyxl`) وبعدين ارفع التغييرات. السكريبت بيطبعلك ألعاب من غير تصنيف أو من غير أيقونة.

## فيديو التريلر
في Genres.xlsx عمود D "فيديو": الصق لينك يوتيوب للعبة (أي شكل) أو الـID بس، وشغّل `python update.py` — الفيديو بيظهر جوه نافذة التفاصيل. اللعبة اللي من غير لينك بتفتح بحث يوتيوب عن التريلر.

## لوحة التحكم (للمالك)
افتح `https://USERNAME.github.io/admin.html`.
- **الدخول:** أول مرة بتحط GitHub Token (Fine-grained، على المستودع ده بس، صلاحية Contents: Read and write) وتختار باسورد. التوكن بيتشفّر بالباسورد على جهازك. اللوحة بتقفل لوحدها بعد 10 دقايق من غير استخدام، وفيها زر 🔒 قفل. نسيت الباسورد؟ "إعداد جديد" من شاشة الدخول.
- **المخزون والتعديل:** لكل لعبة أو أكونت أو منتج: متوفر/نفذت، إخفاء/إظهار، و✏️ تعديل لأي حاجة: الاسم الظاهر، السعر (أو أسعار Off/Online/Pr في غير معدّل)، العلامات، التصنيف، النبذة، عدد اللاعبين، التريلر، الغلاف أو صورة الملحق. وفي الأكونت تقدر تضيف وتشيل وتغيّر الألعاب اللي جواه.
- **لعبة جديدة:** في أي قسم: معدّل، غير معدّل، أكونتات PS4، أكونتات PS5، أو الاتنين. **ملحق جديد:** بصورته.
- **إعدادات الموقع:** أرقام الواتساب وسعر كل قسم معدّل الافتراضي.
- **التراجع والسجل:** زر ↶ تراجع بيرجّع آخر تعديل قبل النشر. تبويب **السجل** بيعرض آخر 20 نشر مع ملخص كل واحد، و"استرجاع" بيرجّع اللوحة لأي نسخة منهم (بعدها دوس نشر).
- كل ده بيتحفظ في `data/live.json`، وبيظهر للزباين بعد **نشر التعديلات** بدقيقة تقريبًا. تعديلات اللوحة بتتغلب على الإكسيل للعنصر اللي اتعدّل.
- **تحذير:** بعد ما تبدأ تستخدم اللوحة، مترفعش `data/live.json` ولا فولدرات `g` و`og` و`icons-extra` و`products` من نسخة قديمة على جهازك، لأنها هتمسح تعديلات اللوحة.

## مشاركة الألعاب على واتساب
كل لعبة ليها صفحة `g/اسم-اللعبة.html` فيها غلافها، ودي اللي بيتبعت لينكها عند المشاركة (الواتساب بيعرض غلاف اللعبة بدل اللوجو). `python update.py` بيعملها لكل الألعاب ومحتاج `pip install openpyxl pillow`. `site_url` في `config.json` لازم يكون لينك موقعك. لينكات المشاركة القديمة لسه بتشتغل بس هتعرض اللوجو.

## رفع الموقع بأمر واحد
`python publish.py` ← يسألك عن المستودع والفرع والتوكن (نفس توكن اللوحة بيشتغل)، ويرفع الملفات اللي اتغيرت بس في commit واحد. مبيمسحش حاجة، ومبيلمسش `data/live.json` لو موجود في المستودع، فمتخافش على تعديلات اللوحة. المستودع لازم يكون فيه commit واحد على الأقل (اعمله بـ"Add a README file").
